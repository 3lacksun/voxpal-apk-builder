# voxpal-apk-builder

Public CI runner that assembles the Android release APK for the **VoxPal — AI Companion** app.

## Why this repository is public

GitHub Actions minutes are free and unlimited for **public** repositories. The application
source lives in the private mirror `3lacksun/voxpal-apk`, but that repository's
private-repository Actions minute allowance is exhausted, so jobs queued there never receive
a runner (they fail in a few seconds with zero steps). Running the build here avoids that
limit.

## Is the source code published here?

No. This repository contains only the build workflow. The application source is attached to a
**draft** release (`voxpal-src`); draft releases are not visible to the public, and the build
job downloads the asset using this repository's own `GITHUB_TOKEN`.

## Running a build

1. Update the snapshot asset on the `voxpal-src` draft release.
2. Actions → **Build VoxPal APK** → *Run workflow*.
3. Download the `voxpal-release-apk` artifact when the run finishes.

The produced APK is signed with the standard Android debug key generated by `expo prebuild`,
so it installs directly on a device for personal use. It is not suitable for Play Store
distribution.
